#### Priority Issues
- **[P1] Incongruous Native Browser Dialogues (`window.confirm` / `alert`)**
  - **Why it matters**: Canvas wipe, sample reset, and entity deletion use raw unstyled browser popups, undermining executive presentation confidence and risking accidental dismissals.
  - **Fix**: Replace all native prompts with a themed, accessible `ConfirmationModal` with keyboard focus trap and explicit destruction warnings.
  - **Suggested command**: `/impeccable clarify` or `/impeccable harden`

- **[P1] AppHeader Cognitive Clutter & Lack of Action Chunking**
  - **Why it matters**: AppHeader crams 8+ controls (Title, Ref, Sibling Sort, Director Cap, Line Style, Tidy, Reset, Import, Export, Settings) into a single row, violating Miller's Law and Hick's Law.
  - **Fix**: Distill header into 3 semantic clusters: Document Metadata, View/Layout Popover (Sort, Cap, Lines), and Primary Action Group (Auto-Tidy, Import, Export CTA).
  - **Suggested command**: `/impeccable distill`

- **[P2] Flat Tree Outline Tab Lacks Hierarchical Indentation**
  - **Why it matters**: The "Tree" tab displays a flat vertical list rather than an indented parent-child tree, defeating the primary mental model of corporate entity tiers.
  - **Fix**: Render entities in a recursive indented hierarchy reflecting incoming/outgoing ownership links.
  - **Suggested command**: `/impeccable shape`

- **[P2] Sub-Legible Micro-Typography (`text-[8px]` & `text-[9px]`)**
  - **Why it matters**: Severe legibility fatigue on high-DPI displays (1440p/4K), violating accessibility guidelines for body and badge text.
  - **Fix**: Re-baseline minimum font scale to 10px/11px with increased line-height and balanced badge padding.
  - **Suggested command**: `/impeccable polish`

- **[P3] Absence of Keyboard Shortcut Infrastructure (Alex Persona)**
  - **Why it matters**: Power users and trust administrators must use the mouse for every operation; no hotkeys for Zoom-to-fit (`F`), Auto-Tidy (`Ctrl+Shift+L`), or New Entity (`Ctrl+N`).
  - **Fix**: Implement global keyboard listeners and an in-app shortcut cheat-sheet drawer (`?`).
  - **Suggested command**: `/impeccable adapt`
